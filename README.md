# FLBingo-FoW-Bookmarklet
Bookmarklet to enable Fog of War mode on a Bingosync board targeted towards DELTARUNE Speedrunning Bingo

## Features
- **Fog of War mode:** You only get to see the goals that your team has unlocked by completing the adjacent goals (four cardinal directions).
- **SRL compatibility:** If you're playing SRL, you can choose how many tiers you have unlocked from the beginning. You can also start from the middle square if you're playing with a regular randomized board.
- **Spectator mode:** Shows the goals unlocked by every team at once, ideal for people who are just watching the match.
- **Various QoL tweaks:**
  - Goal list gets pasted automatically when generating a new board
  - Option to blur goal input list to avoid spoilers
  - Convenient link to document containing details about every goal
- **Christmas Kawkaw!** <br>

## How to install and use
1. Download the [latest release](https://github.com/marti005/FLBingo-FoW-Bookmarklet/releases/latest) of the bookmarklet
2. Right click on the bookmarks bar in your browser and select "Add bookmark" (or similar)
3. Paste the content of the downloaded file into the URL field and set the name to whatever you want
4. Create or join a [Bingosync](bingosync.com) room
5. Click on the bookmarklet icon you added earlier. There should be a popup indicating that the gamemode has been enabled successfully
